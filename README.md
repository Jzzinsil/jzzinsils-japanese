# jzzinsil's japanese

하루에 네 가지만 보는 일본어 학습 페이지. **일본어 · 한국 발음 · 뜻**만 남기고 나머지는 접어뒀습니다.
빌드 도구도 웹폰트도 없이 돌아가고, 진도는 브라우저(localStorage)에 저장됩니다.

```
01  カタカナ    ア        아          a · 2획 · 阿에서 유래 · 짝 あ
02  ひらがな    あ        아          a · 3획 · 安에서 유래
03  단어        大丈夫    다이조-부    괜찮아 / 문제없어
04  문장        명사 + です           긍정·부정·과거·과거부정을 표로
```

한 화면을 위에서 아래로 훑으면 그날 몫이 끝납니다. 다 봤으면 아래 **오늘 다 봤어요**를 누르고,
다음 날 열면 자동으로 Day+1로 넘어갑니다. `‹ ›` 화살표(또는 `←` `→` 키)로 아무 날이나 다시 볼 수 있습니다.

## 디자인

kimi.com의 톤을 참고했습니다 — 웜 오프화이트 배경, 순백 카드, 헤어라인 보더, 거의 무채색.
색으로 강조하지 않고 **크기와 여백**으로만 위계를 만들어서 시선이 일본어에 먼저 닿게 했습니다.

| 요소 | 처리 |
|---|---|
| 일본어 | 가장 크게, 가장 진하게 (카나 최대 168px) |
| 한국 발음 | 그 아래 21px — 읽는 법이 바로 눈에 들어오게 |
| 뜻 · 부가정보 | 흐린 회색, 작게 |
| 획수 · 어원 · 뉘앙스 팁 · 쓰기 연습 | `+ 자세히`에 접어둠 |

시스템 폰트만 씁니다 (일본어는 Hiragino → Yu Gothic → Noto Sans JP 순 폴백). 네트워크 요청이 0건이라 즉시 뜹니다.

## 한국 발음 표기 규칙

`data/kana2kr.js`가 가나 읽기를 한글로 자동 변환합니다. 규칙은 발음 학습에 맞췄습니다.

- **무성음은 격음, 유성음은 평음** — か 카 / が 가, た 타 / だ 다. 눈으로 구별되게.
- **장음은 `-`** — コーヒー 코-히-, 大丈夫 다이조-부. ビル(빌딩)과 ビール(맥주)를 구분해야 하니까.
- **っ은 ㅅ받침** — 切手 킷테, 一緒に 잇쇼니.
- **ん은 뒤 소리에 따라** — せんぱい 셈파이(ㅁ), にほんご 니홍고(ㅇ), でんしゃ 덴샤(ㄴ).
- **조사 は·へ는 소리대로** — 私は 와타시와, 東京へ 토-쿄-에.

## 46일 커리큘럼

| 트랙 | 내용 |
|---|---|
| 가타카나 | 오십음도 46자 — 어원 한자, 헷갈리는 짝(シ/ツ, ソ/ン, ク/ワ/フ) 구별법 |
| 히라가나 | 오십음도 46자 — 어원 한자, 조사 예외(は=와, へ=에) |
| 단어 | 지금 일본에서 실제로 쓰는 46개 — 상황별 예문 + 뉘앙스 팁 |
| 문장 | 명사문 → い형용사 → な형용사 → 동사 활용 → 문장 연결 (46문형) |

```
Day 1~9    명사문     です · じゃないです · でした · じゃなかったです · 반말 4형태 · 조사
Day 10~17  い형용사   ~い · ~くない · ~かった · ~くなかった · いい 불규칙 · ~くて · ~くなる
Day 18~23  な형용사   ~です · ~じゃない · ~でした · ~じゃなかった · い/な 구별 함정
Day 24~32  동사       3그룹 분류 · ます/ません/ました/ませんでした · 사전형/ない/た/なかった
Day 33~46  연결       て형 · ~ている · ~たい · 가능형 · ~なきゃ · ~たら/ば/なら · 총정리
```

오십음도 밖의 소리(濁音·半濁音·拗音·促音·長音)는 **복습 → 발음 규칙**에 참고표로 있습니다.

## 기능

- **발음 재생** — 브라우저 음성 합성(ja-JP). 글자·단어·예문·활용형 모든 줄에 버튼
- **오십음도 도표** — 5열 정렬로 실제 五十音 배치, 배운 글자만 진하게, 각 칸에 한글 발음
- **복습** — 배운 단어·문형 목록, 발음 규칙표, Day 이동, 진도 초기화
- **연속 학습일** — 어제 하고 오늘 하면 +1
- **쓰기 연습** — `자세히`를 펼치면 연한 글자 위에 따라 쓰는 캔버스
- **라이트 / 다크** — 시스템 설정 자동 감지 + 수동 전환
- **키보드** — `←` `→` 날짜 이동, `Esc` 복습 닫기

## Vercel 배포

[vercel.com/new](https://vercel.com/new) → 저장소 선택 → Framework Preset **Other**, 빌드 명령·출력 디렉터리는 비워두고 Deploy.
정적 파일이라 그대로 서빙됩니다. CLI로는 `npx vercel --prod`.

## 늘리기

`data/*.js`의 **배열 순서 = Day 순서**입니다. 47일차부터 이어가려면 네 파일에 같은 개수만큼 항목을
추가하고 `app.js` 상단의 `TOTAL`을 바꾸면 됩니다.

```js
var TOTAL = 46;
```

## 참고

예문의 상황 라벨(브이로그, 이자카야, 회사 단톡방 등)은 그 표현이 실제로 쓰이는 장면을 적은 것이고,
특정 영화·영상의 대사를 인용한 것은 아닙니다. 문장은 모두 현대 일본어에서 자연스러운 형태입니다.
