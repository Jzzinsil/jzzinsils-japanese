# jzzinsil's japanese

**비즈니스 일본어**를 하루에 조금씩. 시험 대비가 아니라 실제 업무에서 쓰는 존댓말·경어만 담았습니다.
빌드 도구도 웹폰트도 없이 돌아가고, 진도는 브라우저(localStorage)에 저장됩니다.

```
Day 1~46    01 가타카나   02 히라가나   03 단어      04 문장 만드는 법
Day 47~     01 단어       02 활용 문장  03 자주 쓰는 표현  04 비즈니스 문장  05 숫자
```

한 화면을 위에서 아래로 훑으면 그날 몫이 끝납니다. **오늘 다 봤어요**를 누르면 다음 날 자동으로 Day+1.
`‹ ›` 화살표(또는 `←` `→` 키)로 아무 날이나 다시 볼 수 있습니다.

## 문체 원칙

이 서비스에 들어가는 모든 일본어 문장은 아래 기준을 지킵니다.

- **です・ます체 이상.** 가능하면 尊敬語(상대를 높임)·謙譲語(자기를 낮춤)까지.
- **속어·유행어 금지** — ヤバい, めっちゃ, マジ, ~じゃん
- **반말 종결 금지** — ~だ, ~だよ, ~な, ~わ, 사전형 종결
- **구어 축약 금지** — ~てる, ~なきゃ, ~とか, ~ちゃう
- **맥락은 업무로** — 사내 보고, 회의, 메일, 전화 응대, 고객 방문, 일정 조정, 사과, 견적·계약

사전형·ない형·た형은 `~たら`·`~たことがございます` 같은 상위 문형을 만드는 **재료**로만 다루고,
"이 형태로 문장을 끝내면 반말"이라는 경고를 함께 붙였습니다.

### 숫자 트랙 (Day 47~86)

조수사는 숫자마다 음이 변해서 따로 익혀야 합니다. 40일간 겹치지 않게 배치했습니다.

```
LV1  기본 수 → ひとつ·ふたつ → 人(ひとり·ふたり) → 日(ついたち·ふつか) → 時(よじ·くじ)
     → 分(ふん/ぷん) → 個 → 枚 → 本(ほん/ぼん/ぽん) → 円
LV2  時間 → 週間 → か月 → 月(しがつ·しちがつ·くがつ) → 年 → 歳(はたち) → 回 → 階(さんがい) → 杯 → 匹
LV3  백·천 음편 → 만·억·조 → % → 倍 → 割 → ポイント → 前年比 → 台 → 名 → 冊
LV4  第~ → ~番目 → 분수 → 소수 → 概数(強·弱) → 단위 → 四半期 → 件 → 年度 → 大台
```

### Day 87~ · 복습 순환

간격 13일로 순환해서 **40일을 한 번도 겹치지 않고 다 돈 뒤** 다시 시작합니다
(87→47, 88→60, … 126→74, 127→47). 콘텐츠를 추가하면 자동으로 늘어납니다.

## 한국 발음 표기 규칙

`data/kana2kr.js`가 가나 읽기를 한글로 자동 변환합니다.

- **무성음은 격음, 유성음은 평음** — か 카 / が 가, た 타 / だ 다. 눈으로 구별되게.
- **장음은 `-`** — 코-히-, 쇼-치. ビル(빌딩)과 ビール(맥주)를 구분해야 하니까.
- **っ은 ㅅ받침** — 킷테, 잇쇼니.
- **ん은 뒤 소리에 따라** — 셈파이(ㅁ), 니홍고(ㅇ), 덴샤(ㄴ).
- **조사 は·へ는 소리대로** — 와타시와, 토-쿄-에.

### 데이터 작성 시 주의 (변환기 함정)

`rd` 필드는 **히라가나·가타카나만**, **어절마다 공백**으로 씁니다. 붙여 쓰면 장음으로 오인됩니다.

| 함정 | 잘못된 출력 | 회피 |
|---|---|---|
| 같은 모음이 어절 경계에서 만남 | `たべたあとで` → 타베타-토데 | `たべた あとで` |
| `の`/`と` + `う` | `けんとうのうえ` → …노-에 | `けんとうの うえ` |
| `お` 접두어 + `う` | `おうかがい` → 오-카가이 | `お うかがい` 또는 `うかがい` |
| 조사 `は` 뒤에 가나가 바로 옴 | `きょうはねる` → 쿄-하네루 | `きょうは ねる` |

## 기능

- **발음 재생** — 브라우저 음성 합성(ja-JP). 모든 일본어 줄에 버튼
- **오십음도 도표** — 5열 정렬로 실제 五十音 배치, 배운 글자만 진하게, 각 칸에 한글 발음
- **복습** — 배운 단어·문장·숫자 목록, 발음 규칙표, Day 이동, 진도 초기화
- **연속 학습일** — 어제 하고 오늘 하면 +1
- **쓰기 연습** — `자세히`를 펼치면 연한 글자 위에 따라 쓰는 캔버스
- **라이트 / 다크** — 시스템 설정 자동 감지 + 수동 전환
- **키보드** — `←` `→` 날짜 이동, `Esc` 복습 닫기

## 배포

GitHub에 push하면 Vercel이 자동으로 재배포합니다.

```bash
git add -A && git commit -m "커리큘럼 수정" && git push
```

새로 연결할 때는 [vercel.com/new](https://vercel.com/new) → 저장소 선택 → Framework Preset **Other**,
빌드 명령·출력 디렉터리는 비워두고 Deploy.

## 늘리기

`data/advanced.js`와 `data/numbers.js`의 **배열 순서 = Day 순서**입니다. 두 파일에 같은 개수만큼
항목을 추가하면 마지막 날이 자동으로 뒤로 밀리고 복습 순환도 그만큼 길어집니다. 코드 수정은 필요 없습니다.

추가하면 좋을 비즈니스 조수사: `~部`(부수) · `~通`(서류) · `~点`(항목) · `~社` · `~営業日` · `~期` · `~泊` · `~か所`
